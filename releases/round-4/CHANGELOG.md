# CHANGELOG —— Round 4 副本（2026-10-04）

版本快照：v2.5 历史详情、首次引导与资料库再扩充。本阶段不发布 GitHub Release，
产物仅做本地归档。

## 本轮改进

1. **内置资料库扩充至 26 条（13 个分类）**
   - 新增 2 条：存档损坏/level.dat 无法加载（分类“存档”，出处 Minecraft Wiki
     存档恢复教程）、资源包加载失败 Failed to load resource pack（分类“资源包”）。
2. **历史页详情面板**：点击操作历史条目，下方即时显示该条记录的详情
   （如修复动作的文件列表、新报错摘要），无详情时提示“该记录无详细内容”。
3. **首次启动引导**：未配置 DeepSeek API Key 时，启动后右下角 toast 提醒 +
   检测页提示“先在设置中填写 API Key”，降低新用户“点了分析没反应”的困惑。
4. **设置页关于区**：底部显示版本与能力信息
   （🧿 TotemFix v2.4 · 本地运行 · 内置资料库 N 条 · DeepSeek 驱动）。
