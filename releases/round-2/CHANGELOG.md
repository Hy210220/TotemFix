# CHANGELOG —— Round 2 副本（2026-10-04）

版本快照：v2.3 左侧导航重构。本阶段不发布 GitHub Release，产物仅做本地归档。

## 本轮改进（UI 全面参考 OpenFrp 重设计 · 第 1 步）

1. **OpenFrp 式左侧导航栏**
   - 新增 168px 宽侧边导航：Logo 区（🧿 TotemFix + 副标题）→ 分隔线 →
     三个导航项（🔍 报错检测 / 💬 AI 问答 / 🕘 历史与备份）→ 底部（⚙️ 设置按钮 + 版本号）；
   - 导航项样式：选中态 = 白底 + 左侧 3px 蓝色竖条 + 蓝色加粗文字；
     未选中 = 灰底黑字，悬停浅蓝高亮，带 ToolTip 提示；
   - 页面切换：点击导航项即切换内容区页面（保留 `_select_tab(0/1/2)` 兼容接口）。
2. **顶部工具栏精简**（随内容区显示）：立即扫描、自动修复开关、
   **状态点**（Canvas 圆点：绿=监控中 / 黄=等待 PCL2 启动，随状态自动变色）、
   状态摘要文字；右侧“DeepSeek 驱动 · 蓝白主题 · 全自动修复”说明。
3. **报错检测页双栏布局**：页内左栏 = 问题卡片列表（沿用 v2.2 卡片设计），
   右栏 = 日志摘要 + AI 分析分区卡片 + 修复计划。
4. 移除原顶部 Logo 行与顶栏右侧按钮（功能并入左侧导航），界面更接近
   OpenFrp「侧边导航 + 内容卡片」骨架。

## 本轮“模拟用户操作”发现并修复的问题

1. `__init__` 中 `_build_toolbar()` 被重复调用（新结构下工具栏在 `_build_body`
   内部构建），已删除多余调用；
2. 状态点颜色需随 PCL 定位状态实时切换，`_update_watch_label` 已联动；
3. 问题列表从顶层移入检测页后，空状态提示与选中态刷新逻辑同步调整完毕。
