# CHANGELOG —— Round 3 副本（2026-10-04）

版本快照：v2.4 资料库扩充与实用小功能。本阶段不发布 GitHub Release，产物仅做本地归档。

## 本轮改进

1. **内置资料库扩充至 24 条（11 个分类）**
   - 新增 4 条：光影/OptiFine/Iris 冲突（分类“光影”）、Forge 安装失败（分类“Mod 安装”）、
     Java/游戏路径非法字符与中文路径（分类“系统环境”）、正版登录失败 BadRequest 400（分类“账号”）；
   - 出处：CurseForge 支持文档、Meloong-Git/PCL issue #6642/#6995、中文路径崩溃分析博客、
     CSDN 光影问答等（见 kb_data.json 每条 source）。
2. **详情页新增「📋 复制日志」**：一键把当前报错的日志摘要（含来源与行号）复制到剪贴板，
   方便粘贴给好友或 AI；复制成功右下角 toast 提示。
3. **AI 问答页新增「🗑 清空」按钮**：一键清空对话气泡、对话历史与上下文，恢复欢迎语。

## 本轮“模拟用户操作”发现并修复的问题
