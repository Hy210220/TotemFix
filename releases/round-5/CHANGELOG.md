# CHANGELOG —— Round 5 副本（2026-10-04）· 循环收官

版本快照：v2.6 收官打磨。本阶段不发布 GitHub Release，产物仅做本地归档。
本副本为 5 轮「改进 → 模拟用户 → 修复」循环的最后一轮。

## 本轮改进

1. **内置资料库扩充至 28 条（13 个分类）**
   - 新增 2 条：JVM 自身崩溃（hs_err_pid / A fatal error has been detected，
     含 Problematic frame 定位法）、找不到主类（Could not find or load main class）。
2. **资料库分类徽章配色**：13 个分类按语义着色（OpenFrp 风格）——
   显卡=红、内存=绿、联机=蓝、光影=紫、Mod=橙、系统环境=灰等。
3. **设置页补齐「自动修复」开关**：与顶栏开关双向联动（行为设置区首项）。
4. **状态栏页面提示**：切换左侧导航页面时，状态栏显示“当前页面：报错检测/AI 问答/历史与备份”。

## 本轮“模拟用户操作”发现并修复的问题

1. `_show_page` 在窗口构建期间被调用时，状态栏尚未创建 → `_set_status` 抛
   AttributeError，已加保护（构建期调用静默忽略）。
2. 设置页新增 autofix 开关后，冒烟新增联动断言（设置页关闭 → 顶栏同步关闭）。
